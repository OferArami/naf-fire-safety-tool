# עדכון חודשי של נתוני הדרישות — "בונה תוכנית בטיחות אש"

רשות הכבאות וההצלה מפרסמת ב-data.gov.il קובץ חדש של הדרישות פעם בחודש, בדרך כלל בתחילת החודש:
- היתרי בנייה: https://data.gov.il/he/datasets/firefightingcommission/prvbuildingquirement
- רישוי עסקים: https://data.gov.il/he/datasets/firefightingcommission/businessreq

העדכון לוקח כמה דקות ויש בו 4 צעדים.

התיקייה הזו נמצאת בתוך ה-repo של האתר: `C:\naf-fire-safety-tool\tools\update_pipeline`. כך היא מגיעה לשותף עם כל Pull, ותמיד תואמת לאתר. את הפקודות מריצים מתוכה.

## מה צריך (פעם אחת)
- Python 3 מותקן במחשב (בדיקה: לפתוח את שורת הפקודה, ולהקליד `python --version`). אין צורך להתקין ספריות.
- GitHub Desktop עם ה-repo של האתר (אצלנו `C:\naf-fire-safety-tool`).

## צעד 1 — הורדת הנתונים (בדפדפן, כדקה)
1. נכנסים ל-https://data.gov.il
2. F12 ← לשונית Console ← מדביקים את כל התוכן של `opendata_download.js` ← Enter.
   אם Chrome מבקש לאשר הדבקה, מקלידים `allow pasting` ואז מדביקים שוב.
3. בסוף יורדים לתיקיית ההורדות שלושה קבצים: `permit.json`, `business.json`, `opendata_meta.json`.
   הסקריפט מוצא לבד את הקובץ החודשי העדכני ביותר בכל מאגר. אין להשתמש במזהה קובץ קבוע.

## צעד 2 — בנייה ובדיקה (שורת פקודה, פחות מדקה)
מתוך התיקייה `update_pipeline`:
```
python run_update.py --repo C:\naf-fire-safety-tool
```
הפקודה:
- לוקחת את שלושת הקבצים מתיקיית ההורדות ובודקת שההורדה שלמה;
- עוצרת ואומרת "אין נתונים חדשים" אם הקובץ לא חדש ממה שכבר באתר;
- בונה את האתר החדש ומתקנת אוטומטית שורות שבורות בקובץ של הרשות (פירוט ב-`output/build_report.json`);
- מציגה סיכום שינויים מול האתר הנוכחי. הדוח המלא נשמר ב-`output/diff_report.txt`.

כדאי להציץ בדוח. אם יש בו מאות שינויים בבת אחת, או קבוצה שלמה שנעלמה, עדיף לבדוק לפני שמפרסמים.

## צעד 3 — העתקה ל-repo
```
python run_update.py --repo C:\naf-fire-safety-tool --copy
```
מעתיק את `index.html` ואת התיקייה `data/` לתוך ה-repo, ומוחק משם רק קבצי קבוצות שכבר לא קיימים במאגר.

## צעד 4 — פרסום
ב-GitHub Desktop: Commit עם ההודעה שהפקודה מציעה (למשל `Update fire requirements data to 2026-10-04`) ← Push origin.
אחרי דקה-שתיים האתר מתעדכן. בראש העמוד יופיע "נתוני רשות הכבאות נכון ל-...".

## אם משהו משתבש
- "ההורדה לא הושלמה": מריצים שוב את צעד 1. אם ה-Console מראה שגיאה, האתר של data.gov.il כנראה לא זמין זמנית.
- הקבצים לא נמצאו בהורדות: אפשר לשים אותם ידנית בתיקייה `opendata/` (באותם שמות) ולהריץ שוב.
- הדפדפן שמר את הקובץ כ-`permit (1).json`: זה בסדר, הפקודה לוקחת את הגרסה החדשה ביותר.

## קבצים
| קובץ | תפקיד |
|---|---|
| `opendata_download.js` | הורדת הנתונים העדכניים מ-data.gov.il (בדפדפן) |
| `run_update.py` | מריץ את כל השלבים בפקודה אחת |
| `03b_build_from_opendata.py` | בונה את קבצי `data/` ומתקן שורות שבורות בקובץ הרשות |
| `04_inject_html.py` | בונה את `index.html` מתוך `../site_template.html` |
| `05_diff_report.py` | דוח מה השתנה מול ה-repo |
| `common.py` | נתיבי תיקיות משותפים |
| `archive_old_govil_route/` | הדרך הישנה (משיכה מ-gov.il). חסומה ע"י Cloudflare, לא בשימוש, נשמרה לתיעוד בלבד |

שינויים בעיצוב או בלוגיקה של האתר נעשים ב-`site_template.html` (תיקייה אחת למעלה), ולא ב-`index.html` שבתוך ה-repo, כי הוא נבנה מחדש בכל עדכון.
